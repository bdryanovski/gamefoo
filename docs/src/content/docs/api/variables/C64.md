Defined in: [core/palettes/commodore64.ts:59](https://github.com/bdryanovski/gamefoo/blob/main/src/core/palettes/commodore64.ts#L59)

Commodore 64 16-color palette.

Uses the widely-accepted "Pepto" palette values, which accurately
represent the colors as displayed on period-correct monitors.

## Since

0.5.0

## Example

```ts
// Classic C64 blue screen
ctx.fillRect(0, 0, 320, 200, C64.named.BLUE);
ctx.fillRect(10, 10, 300, 180, C64.named.LIGHT_BLUE);

// Text in light blue on blue (iconic C64 look)
ctx.drawText('READY.', 10, 10, C64.named.LIGHT_BLUE);
```
