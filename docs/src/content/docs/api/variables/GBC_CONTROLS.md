Game Boy Color control scheme.

Physical layout (same as Game Boy):
```
                  [A]
  [D-PAD]      [B]

     [SELECT] [START]
```

Keyboard mapping:
- D-pad: WASD or Arrow keys
- A button: X or J
- B button: Z or K
- Start: Enter
- Select: Shift
